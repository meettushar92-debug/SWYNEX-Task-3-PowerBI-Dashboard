# SWYNEX – Online Retail Sales Analysis Dashboard

## Project Overview

This project was completed as part of my Data Analyst Internship at SWYNEX Technologies.

The project focuses on analyzing an Online Retail dataset and presenting key findings through a dashboard created using Microsoft Power BI.

## Project Objectives

- Analyze revenue and quantity metrics
- Compare revenue across countries
- Understand daily revenue trends
- Identify the top 10 products by revenue
- Analyze negative quantity transactions

## Dashboard Highlights

- Total Revenue
- Average Order Value
- Total Quantity
- Negative Quantity
- Revenue by Country
- Revenue Share by Country
- Top 10 Products by Revenue
- Daily Revenue Trend
- Negative Quantity by Country

## Tools Used

- Microsoft Power BI
- Online Retail Dataset
- Data Visualization and Exploratory Data Analysis

## Key Findings

- Total Revenue: 192,734.82
- Average Order Value: 420.82
- Highest Daily Revenue: 68,027.59 on 3 December
- Negative Quantity: -240
